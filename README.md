🟢 سطح ۱ — مبانی JavaScript
1. اطلاعات شخصی

متغیرهایی برای نام، سن، شهر و شغل یک شخص ایجاد کنید و همه را در Console نمایش دهید.

2. محاسبه سن

سال تولد را در یک متغیر قرار دهید و سن شخص را محاسبه کنید.

3. محاسبه قیمت

قیمت یک کالا و تعداد آن را در متغیر قرار دهید و مبلغ کل را محاسبه کنید.

4. کیف پول

موجودی کیف پول و قیمت یک بازی را دریافت کنید و مشخص کنید آیا کاربر توانایی خرید بازی را دارد یا خیر.

5. تبدیل دما

دمای سانتی‌گراد را دریافت کنید و آن را به فارنهایت تبدیل کنید.

6. تشخیص زوج و فرد

یک عدد دریافت کنید و مشخص کنید زوج است یا فرد.

7. مقایسه دو عدد

دو عدد دریافت کنید و بزرگ‌تر را نمایش دهید.

8. تشخیص نمره

نمره دانش‌آموز را دریافت کنید و مشخص کنید:

مردود
قبول
خوب
عالی
9. ماشین حساب ساده

دو عدد و یک عملگر + - * / دریافت کنید و نتیجه را محاسبه کنید.

10. تشخیص عدد

یک عدد دریافت کنید و مشخص کنید:

مثبت است
منفی است
صفر است
🟡 سطح ۲ — شرط و حلقه
11. بزرگ‌ترین عدد

سه عدد دریافت کنید و بزرگ‌ترین آن‌ها را پیدا کنید.

12. سال کبیسه

یک سال دریافت کنید و مشخص کنید سال کبیسه است یا خیر.

13. رمز عبور

یک رمز عبور از کاربر دریافت کنید. اگر رمز صحیح بود پیام ورود موفق و در غیر این صورت پیام خطا نمایش دهید.

14. سیستم ورود

نام کاربری و رمز عبور را دریافت کنید و در صورت صحیح بودن هر دو، اجازه ورود بدهید.

15. شمارش اعداد

اعداد ۱ تا ۱۰۰ را چاپ کنید.

16. اعداد زوج

اعداد زوج بین ۱ تا ۱۰۰ را چاپ کنید.

17. مجموع اعداد

اعداد ۱ تا ۱۰۰ را با حلقه جمع کنید.

18. جدول ضرب

یک عدد دریافت کنید و جدول ضرب آن را از ۱ تا ۱۰ نمایش دهید.

19. فاکتوریل

یک عدد دریافت کنید و فاکتوریل آن را محاسبه کنید.

20. بازی حدس عدد

یک عدد مخفی در برنامه قرار دهید. کاربر باید آن را حدس بزند و برنامه مشخص کند حدس او:

بزرگ‌تر است
کوچک‌تر است
درست است.
🟠 سطح ۳ — Array
21. لیست نمرات

آرایه‌ای شامل ۱۰ نمره بسازید و تمام نمرات را چاپ کنید.

22. میانگین نمرات

آرایه‌ای از نمرات داشته باشید و میانگین آن‌ها را محاسبه کنید.

23. پیدا کردن بزرگ‌ترین

آرایه‌ای از اعداد بسازید و بزرگ‌ترین عدد را پیدا کنید.

24. پیدا کردن کوچک‌ترین

کوچک‌ترین عدد موجود در یک آرایه را پیدا کنید.

25. شمارش اعداد زوج

در یک آرایه مشخص کنید چند عدد زوج وجود دارد.

26. جستجوی نام

آرایه‌ای از نام دانش‌آموزان بسازید. نامی از کاربر دریافت کنید و بررسی کنید آیا این دانش‌آموز در لیست وجود دارد یا خیر.

27. حذف یک عنصر

یک آرایه از نام‌ها داشته باشید و نام مشخصی را از آرایه حذف کنید.

28. مرتب‌سازی

آرایه‌ای از اعداد ایجاد کنید و آن را از کوچک به بزرگ مرتب کنید.

29. تبدیل قیمت‌ها

آرایه‌ای از قیمت محصولات داشته باشید و قیمت همه محصولات را ۱۰٪ افزایش دهید.

30. فیلتر نمرات

آرایه‌ای از نمرات داشته باشید و فقط نمرات بالاتر از ۱۰ را در یک آرایه جدید قرار دهید.

31. اطلاعات دانش‌آموز

32. چند دانش‌آموز

آرایه‌ای از Objectهای دانش‌آموز بسازید و نام همه دانش‌آموزان را نمایش دهید.

33. دانش‌آموز ممتاز

آرایه‌ای از دانش‌آموزان داشته باشید و دانش‌آموزانی که نمره بالاتر از ۱۸ دارند پیدا کنید.

34. محصول فروشگاه

35. لیست محصولات

آرایه‌ای از محصولات ایجاد کنید و فقط محصولاتی را که قیمت آن‌ها کمتر از یک مقدار مشخص است پیدا کنید.

36. تابع سلام

تابعی بنویسید که نام شخص را دریافت کند و پیام مناسب برای او ایجاد کند.

37. تابع محاسبه

تابعی بنویسید که دو عدد دریافت کند و حاصل جمع آن‌ها را برگرداند.

38. ماشین حساب با Function

برای عملیات زیر تابع جداگانه ایجاد کنید:

جمع
تفریق

سپس یک ماشین‌حساب ساده بسازید.

39. تابع تشخیص زوج

تابعی بنویسید که یک عدد دریافت کند و مشخص کند زوج است یا فرد.

40. تابع محاسبه میانگین

تابعی بنویسید که یک آرایه از اعداد دریافت کند و میانگین آن‌ها را برگرداند.

🔴 سطح ۵ — ES6 و مفاهیم مهم‌تر
41. Destructuring

یک Object مربوط به یک کاربر بسازید و با استفاده از Object Destructuring نام، سن و شهر او را استخراج کنید.

42. Array Destructuring

یک آرایه شامل پنج رنگ ایجاد کنید و با استفاده از Array Destructuring سه رنگ اول را داخل متغیرهای جداگانه قرار دهید.

43. Spread Operator

دو آرایه از نام دانش‌آموزان ایجاد کنید و با استفاده از Spread Operator آن‌ها را در یک آرایه جدید ترکیب کنید.

44. Rest Parameter

تابعی ایجاد کنید که بتواند هر تعداد عدد دریافت کند و مجموع تمام اعداد را محاسبه کند.

45. Template Literal

برای یک محصول Object بسازید و با استفاده از Template Literal یک متن کامل برای معرفی محصول ایجاد کنید.

مثلاً اطلاعاتی مانند نام محصول، قیمت و موجودی در متن قرار بگیرد.

46. Callback

تابعی ایجاد کنید که یک تابع دیگر را به‌عنوان پارامتر دریافت کند و آن تابع را اجرا کند.

47. map

آرایه‌ای از قیمت محصولات داشته باشید و با استفاده از map قیمت جدید تمام محصولات را با ۲۰٪ افزایش ایجاد کنید.

48. filter

آرایه‌ای از کاربران داشته باشید که هر کاربر شامل نام و سن است. با استفاده از filter فقط کاربران بالای ۱۸ سال را جدا کنید.

49. reduce

آرایه‌ای از قیمت چند محصول داشته باشید و با استفاده از reduce مجموع قیمت تمام محصولات را محاسبه کنید.

50. پروژه کوچک — سیستم فروشگاه

یک سیستم فروشگاه ساده با JavaScript طراحی کنید.

اطلاعات هر محصول:

id
name
price
category
stock

سیستم باید بتواند:

لیست محصولات را نمایش دهد.
محصولی را بر اساس نام جستجو کند.
محصولات یک دسته‌بندی خاص را پیدا کند.
محصولات ارزان‌تر از یک قیمت مشخص را پیدا کند.
مجموع قیمت محصولات را محاسبه کند.
محصولات موجود را از محصولات ناموجود جدا کند.
قیمت محصولات را با یک درصد مشخص افزایش دهد.
اطلاعات یک محصول را با Destructuring استخراج کند.
برای نمایش اطلاعات محصول از Template Literal استفاده کند.
منطق جستجو و فیلتر را داخل Functionهای جداگانه قرار دهد.

این تمرین آخر عمداً چند مبحث را با هم ترکیب می‌کند: Array + Object + Function + Condition + Loop + map + filter + reduce + Destructuring + Spread + Template Literal.
